## How to capture

- Browser: Chrome or Edge, dev-tools-free, 1440×900 viewport
- Light mode (the app's warm earthy palette pops more)
- Sign in to the app first so screens have real data
- Use a clean account with realistic items (Milk, Bread, Eggs, Bananas, Chicken, etc.)
- PNG, not JPEG
- Approximate sizes: 1400-1800px wide is ideal — GitHub will scale them down in the README

## Quick capture tip

On Windows: `Win + Shift + S` → window snip mode → click the browser window → file saves to clipboard → paste into Paint → save as PNG into this folder.
